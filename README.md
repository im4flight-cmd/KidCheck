# KidCheck

A children's check-in system for Country Faith Church (CFC).

KidCheck helps our volunteers welcome families quickly, keep track of who is in each room, and make sure every child goes home with the right person. The goal is simple. Give parents peace of mind, and give our ministry a safe and orderly way to serve kids each week.

## Why we are building this

CFC is growing, and a growing kids ministry needs a check-in process that is fast on Sunday morning and safe for every family. This project is our own tool for that, shaped around the way we actually serve.

## Direction

The details are still being decided, so nothing below is final. The direction we are aiming for:

- Family and child records that are easy to add and keep current
- Quick check-in and check-out at the door
- Printed name tags with a matching security code for pickup
- A simple room roster so leaders can see who is present
- Basic reporting for attendance and follow-up

## Project status

Early setup. This repository holds the foundation for now. Tools, framework, and features come next.
